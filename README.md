# 控糖有数 SugarLens-H5

预包装食品营养标签解读与隐形糖识别系统 —— 人工智能专业本科毕业设计。

纯静态手机网页，不依赖后端与构建工具，所有记录只存在使用者本机浏览器。

在线地址：https://mtjvmysnk9-tech.github.io/hidden-sugar-h5/

## 要点

- 标签换算：糖 g/100g(mL) + 份量 → 每份糖克数、方糖块数（4 g/块）、占每日理想 25 g 与上限 50 g 的百分比、能量 kcal 与 NRV%
- 糖行缺失时的处理：不猜测数值，按糖占可利用碳水 0 / 25 / 50 / 100 % 四档做敏感性区间，并在结果页标注"估算"
- 配料表解析：47 个糖源/代糖词条最长匹配（避免"三氯蔗糖"误判成"蔗糖"），按配料递减顺序加权判级，命中 12 条营销话术（"0 蔗糖""无添加糖"等）时给出 GB 7718-2025 的口径提醒
- 拍照识别配料表：调用浏览器端 tesseract.js（中文模型约 1.7 MB，首次点击才下载，图片不上传），从整张标签里定位配料段并填成草稿；实测置信度约 83、单字仍有 5–8% 错，所以必须人工核对后才进解析与数据集
- 声称判定：无糖 ≤0.5 g/100g(mL)、低糖 ≤5 g、比较声称需 ≥25% 差异，均按 GB 28050-2025
- 数据集：内置 8 条带出处的种子条目，管理端可录入实测标签并归档标签照片，导出 19 列 CSV（含照片文件名、录入人、数据性质、来源链接）
- 每日记录：按早餐 / 午餐 / 晚餐 / 加餐四栏记录，显示每餐糖量、当日剩余额度、近 7 天趋势与连续天数
- 知识测评：12 题随机抽 8，答完给分并逐题附标准出处
- 管理入口无默认口令，首次进入由本人设定，本机只存哈希；页面不展示任何口令

## 数据来源口径

标准值只取四类可查文件：GB 28050-2025《预包装食品营养标签通则》（强制标示由"1+4"扩为"1+6"，新增"糖"这一行，2027-03-16 实施）、GB 7718-2025《预包装食品标签通则》、《中国居民膳食指南（2022）》、WHO 2015 糖游离糖指南。内置条目每条都带 `src` 链接与数据性质标注（官方通报 / 第三方实测报道 / 计算值），没有出处的数字不进代码。

能量换算 1 kcal = 4.184 kJ，糖供能 4 kcal/g，能量 NRV 取 8400 kJ。

## 数据采集规范（论文用）

300–500 张标签照片由本人与组员分工实拍，一张照片对应一条词条：

- 编号留空时系统按 `S-0001` 递增生成，照片文件名与编号自动对齐（`S-0137` → `S-0137.jpg`），实体照片与 CSV 行一一对应
- `录入人` 填组员姓名或代号，便于分工核对与致谢
- `数据性质` 由系统按来源自动标注：实测录入 / 带出处种子 / 计算值
- 只拍营养标签与配料表，不拍人脸、门店招牌与价签；原始照片单独存档，仓库只提交 CSV
- 标签上"糖"这一行缺失的（2027-03-16 前的旧包装），留空而不填 0，论文里按敏感性区间报告

## 本地运行

克隆后双击 `index.html` 即可，无需安装依赖。数据落在 `localStorage` 的 `sg_` 前缀键位；`我的 → 查看存储键位` 可列出，`清空本机数据` 一键复位。

## 边界

不做医疗或营养诊断建议；不做联网鉴权，不上传任何用户数据。拍照识别只出草稿：中文单字实测仍有 5–8% 错，核对前不作为结论；标签照片存在本机 IndexedDB，清空本机数据会一并删除，换设备需重新采集或另行存档。
